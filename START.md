# ALP Platform — Start Guide
Built by Stan Paraclete | www.stanparaclete.com

## Step 1 — Open Terminal in VS Code (Ctrl+` or Cmd+`)

## Step 2 — Create the database (run ONCE)
```
createdb alp_db
```

## Step 3 — Start the Backend (Terminal 1)
```
cd 05-backend
npm install
cp .env.example .env
npm run dev
```
✅ You should see: ALP Platform API — http://localhost:4000

## Step 4 — Start the Web App (New Terminal Tab: Cmd+T)
```
cd 02-webapp
npm install
npm run dev
```
✅ You should see: VITE ready — http://localhost:3000

## Step 5 — Open browser
Go to: http://localhost:3000
